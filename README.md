## 🌐 Free Online Hosting (GitHub Pages)

To publish this portfolio live on the web:
1. Create a repository on [GitHub](https://github.com) named `portfolio` (or `pavithra-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `resume.pdf`.
3. Go to **Settings** > **Pages**.
4. Set source to the `main` branch and `/root` folder, then click **Save**.
5. Your portfolio will go live at `https://<your-username>.github.io/<repository-name>/`.
